PERSONAL ASSISTANT · READ-ONLY GMAIL CONNECTOR

Personal information, useful context.

Rojbot is a private personal assistant operated by the owner of this GitHub account. It uses Hermes to help its owner understand selected personal email records and, when requested, save useful summaries in a private Obsidian vault.

What the Gmail connection does

The connector searches and reads personal messages stored in the connected Gmail account, including imported Hotmail messages and sent replies where present. It can extract text from supported PDF attachments to help with travel, purchases, events and other personal organisation. It does not connect directly to Hotmail.

Google authorisation requests gmail.readonly. This scope permits reading mailbox data; the connector can retrieve messages across the connected personal mailbox in response to the owner’s requests. It cannot send, edit or delete email, or mark messages as read.

Personal calendar

An optional Google Calendar connector can list and create events on the owner’s dedicated Rojbot Personal calendar when requested. It uses a separate Calendar authorisation. Google’s permission covers managing events on calendars the owner owns; the connector itself restricts access to the selected secondary calendar and exposes no edit, delete, sharing or guest-invitation tools.

Where processing happens

The connector runs on the owner’s private computer. Selected email content returned to Hermes may be sent to its configured external AI service to answer requests. Requested summaries and source records may be retained in the private vault and backups.

About this website

This is a public information site, not the assistant itself. It provides no sign-in or mailbox access and contains no email records or credentials. Rojbot is for its owner’s personal use and is not offered as a public service.
